# Donnie Burton

I build local AI tools and the systems around them: task workflows, evidence records, application interfaces and the checks that distinguish a reported result from a verified one.

My work spans **Nucleus**, **NOAH**, **Internet of Intelligence / AIIP**, **Parlay**, **DonnieBurton.com** and **Prudent**. This GitHub profile is the public engineering index. Product applications and their private operating data remain separate.

## Developer notes

| Problem | What the work does | Read |
| --- | --- | --- |
| A result is challenged after it was accepted | Preserve the original decision and link the review, complaint and correction | [Decision history](docs/decision-history.md) |
| An agent skill changes after review | Bind review records to exact source revisions and file hashes | [Skill provenance](docs/skill-provenance.md) |
| A job retries the same observation | Persist one local event and reject conflicting retries | [Tool catalog](CATALOG.md#prepared-toolkit) |
| Imported contacts inflate a registration funnel | Track imports, permission evidence, opt-outs and registrations separately | [Tool catalog](CATALOG.md#prepared-toolkit) |

The first portable toolkit has **112 passing local regression tests** and four offline synthetic examples. Its source release is awaiting a reuse-license decision. [Publication status and validation scope](docs/publication-status.md) explain what is ready and what remains held.
